# shoutime

勇哥的第一个 GitHub 仓库，创建于 2026-11-11。

## 这个仓库是什么

一个学习仓库 —— 用来练手 Git 和 GitHub 的完整流程。

## 里面有什么

- `index.html` — 第一个文件：一个能在浏览器打开的小页面

## 今天学会的事

1. Issue 的完整生命周期（创建 → 开启 → 关闭）
2. Token 权限最小化
3. commit（拍快照）与 push（存云端）

## 常用黑话对照

| 黑话 | 人话 |
|------|------|
| commit | 拍一张代码快照 |
| push | 把快照传上云端 |
| clone | 把仓库下载到本地 |
| Issue | 贴在仓库上的便签 |
